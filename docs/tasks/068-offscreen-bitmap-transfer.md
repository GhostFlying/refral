# Blob workers and OffscreenCanvas bitmap transfer

## Goal and dependencies

Build on tasks 061 and 064. Create classic Blob-backed dedicated workers (including workers spawned inside them) with a verifiable selected core wherever the pinned suite requests WebGL. Preserve the upstream script bytes, transferred input/output ownership and original assertions. The OffscreenCanvas presentation API must synchronously transfer the current drawing buffer and leave subsequent reads/draws with a fresh color/depth/stencil buffer, independently of GL bindings, masks and scissor. Context attributes stay stable. Task 070 owns default-buffer discard and preserveDrawingBuffer requests. Task 066 owns immediate HTMLCanvas consumers and requested alpha handling.

## Work and acceptance

- Own the dedicated-worker bootstrap and nesting observations, OffscreenCanvas integration and a small shared host operation for resetting the default attachments. Maintain the public async WebGL factory and the existing GPU executor. Capture the Blob at Worker construction so revocation of the caller's URL after construction does not replace or invalidate its bytes.
- Map the HTML OffscreenCanvas transfer and structured-clone behavior to the pinned WebGL drawing-buffer initialization rules. Test returned bitmap color and fresh clear values, including a currently bound user framebuffer and a mask that disables writes.
- Validate the original offscreencanvas-timer-query.html and offscreencanvas-transfer-image-bitmap.html in headless native/JS/Rust with recorded original counts, worker depth, selected core and images. Recheck the task 064 originals and public worker drawing. Inspect any independent attribute mismatch against task 070. Run TypeScript and deterministic adapter/tool tests.
