# Synchronous Canvas image observation and presentation alpha

The official canvas-test, draw-webgl-to-canvas-test, draw-static-webgl-to-multiple-canvas-test and to-data-url-test observe default-framebuffer writes through ordinary DOM APIs before the current JS task ends. Both cores currently return a transparent image when a clear/draw is still queued. premultiplyalpha-test also checks the context attribute and straight-alpha composition.

Use the pinned WebGL1 drawing-buffer and context creation rules, including the unmodified pixel values from GL readPixels and premultiplication only at the compositing boundary when premultipliedAlpha is false. Verify a common host approach that publishes completed default-framebuffer writes before returning to the caller. Keep FBO draws, uploads and resource lifetime managed by the existing ordered queue. Check submission behavior and costs with actual counters. Retain headless native/JS/Rust output, original assertions and any remaining image-source/cross-frame failures. Retention/discard after compositing belongs to a separate task.

Verify pnpm check, pnpm rust:build, the real Wasm, targeted original files, and existing automatic submission and RTT tests. The host, public attributes and their evidence are the owned areas. Update architecture on verified behavior.
