## Counts against the declared limits

Chrome 158.0.8127.36 reports 16 generic vertex attribute slots. Both Refral cores report 8, matching the compiler/linker profile and the GLES 2.0 minimum. Native Chrome exposes 39 extension names, including the optional ANGLE_instanced_arrays extension. The Refral cores expose four extensions on this build and instancing is outside their profile. Let N be the reported slot count and E be 1 when instancing is available, 0 otherwise. Each original's final successfullyParsed assertion is included below. - **0.** The ordered Cartesian product of float, vec2, vec3 and vec4 yields 16 vertex shaders. Each contributes a compile-success assertion and one rejected aliased link at each valid slot. The captured messages contain exactly 16 link rejections at each reported location, including the last slot. [Original aliasing helper](https://github.com/KhronosGroup/WebGL/blob/39443210f7f81db4773eb104facadfb85d05dfa4/sdk/tests/js/tests/gl-bindattriblocation-aliasing.js)
- **1.** For each matrix width d, the original uses N − d starting positions. It checks d overlapping vector bindings that must fail and one adjacent binding that must link. The lower-bound check and parse assertion add two. The recorded results match every expected position, vector location and link outcome in order. [Original matrix-binding test](https://github.com/KhronosGroup/WebGL/blob/39443210f7f81db4773eb104facadfb85d05dfa4/sdk/tests/conformance/attribs/gl-bindAttribLocation-matrix.html)
- **4.** The shader emits green when a disabled color attribute supplies the default (0, 0, 0, 1). The original checks the rendered canvas at each possible color location, creates a second context for location zero, then checks NO_ERROR and parsing. [Original disabled-attribute test](https://github.com/KhronosGroup/WebGL/blob/39443210f7f81db4773eb104facadfb85d05dfa4/sdk/tests/conformance/attribs/gl-disabled-vertex-attrib.html)
- **8.** For width d, the shader declares N − d vectors and one matrix. Moving its declaration through the list yields N − d + 1 programs. Each program checks shader load, link error, program identity and the matrix location, followed by every vector's location against every matrix column. Chrome's mat2/mat3/mat4 blocks contribute 480/602/676 assertions across 15/14/13 programs. Refral's blocks contribute 112/114/100 across 7/6/5 programs. Both totals include two outer assertions. The audit checks each individual vector and column comparison. For every linked program, all reported slots were occupied exactly once by the matrix columns and the distinct vector locations. This original exercises the linker and reflected locations. Actual matrix draws have separate coverage in task 089. [Original matrix location test](https://github.com/KhronosGroup/WebGL/blob/39443210f7f81db4773eb104facadfb85d05dfa4/sdk/tests/conformance/attribs/gl-matrix-attributes.html) · [Matrix drawing evidence](089-matrix-vertex-input.md)
- **9.** Each slot produces 60 checks from twelve simple scalar/vector setter inputs, each checking Float32Array type and four components. Eight randomized setters add a type and a value check each. The 25 fixed assertions cover context creation, two aggregate NO_ERROR checks, thirteen invalid-index calls, eight invalid array lengths and parsing. Both cores exercise every setter within their published range. Integer vertex setters in the shared helper require WebGL2, which is outside this inventory for all three backends. [Original vertex attribute helper](https://github.com/KhronosGroup/WebGL/blob/39443210f7f81db4773eb104facadfb85d05dfa4/sdk/tests/js/tests/gl-vertex-attrib.js)
- **14.** The first group has two ordinary draw assertions per slot. The second has two ordinary assertions per slot and two extra assertions when the instancing extension is available. The 64-assertion Chrome–Refral difference comprises 32 ordinary checks for Chrome's eight extra locations and 32 instancing checks for Chrome's sixteen locations. The original reports the unavailable extension through a debug message, so all three official skipped counters remain zero. Instancing is an uncovered optional capability for both cores.

The passing counts reconcile across all six originals. Capacity accounts for 2,304 assertions and optional instancing for 32. A future increase to the reported limit must extend the compiler allocation and both cores' actual generic attribute storage. Enabling instancing would add two assertions per reported slot in case 14. Keep these rows visible in the raw differing-count report when the profiles change.
