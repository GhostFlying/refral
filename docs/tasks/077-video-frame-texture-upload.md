# WebCodecs VideoFrame texture sources

The pinned WebGL1 TexImageSource IDL includes VideoFrame. Texture Upload Width and Height uses the source frame in pixels and the WebGL DOM unpack rules. The official image-decoder-to-texture.html decodes an I420 JPEG and checks two corner regions of a textured draw. On the compiler-packing full run both selected cores timed out with zero assertions. The current WebGL facade's overload recognizes HTMLVideoElement and omits VideoFrame.

Extend the existing synchronous platform extractor to accept a genuine branded VideoFrame from the canvas realm or another realm. Keep the decoder frame under caller ownership, consume pixels before return and apply the selected core's texture/format/bounds validation to both definitions and updates. Probe the exact GL error after close, display versus coded/visible sizes, unpack flip and packed formats. Preserve existing source behavior. The shared facade, extractor, support record and browser tests are the owned modules.

Run pnpm check, the original through native/JS/Rust with headless Chrome and a public differential for definitions, updates, immediate caller close, closed-source handling and destination pixels. Retain selected-core identity, original assertion counts and images in artifacts/conformance/campaign/video-frame.
