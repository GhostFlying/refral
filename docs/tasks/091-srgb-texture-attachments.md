# sRGB texture sampling and attachment encoding

Implement the WebGL 1 EXT_sRGB contract following float storage transport from task 084. The extension owns SRGB_EXT and SRGB_ALPHA_EXT UNSIGNED_BYTE image specifications, SRGB8_ALPHA8_EXT renderbuffers, and FRAMEBUFFER_ATTACHMENT_COLOR_ENCODING_EXT. Before activation each generation rejects these enums. The RGB-only texture can be sampled, the sRGB-with-alpha texture and the sized renderbuffer can be attached. Verify color encoding queries for linear and sRGB textures/renderbuffers and validation for missing or unsupported attachment points. Explicit mip levels follow GLES and WebGL's generateMipmap restriction. The texture's RGB channels use the sRGB transfer function and alpha stays linear across typed, image and video sources. Source color-space preferences and display-p3 are tracked independently.

Map these rules to the pinned extension, GLES and original assertions. Own both cores' validation, resource protocol, allocation, pipeline selection, readback and test coverage. Use hardware rgba8unorm-srgb sampling and rendering and preserve encoded bytes at readPixels/copy boundaries. Audit texture and renderbuffer reuse, clears, masked writes, blending and draw-then-sample. Add shared and public regressions for branches missing in the originals. Run pnpm check, pnpm rust:build, pnpm rust:test:wasm, and single-worker headless native/JS/Rust originals ext-sRGB.html and texture-srgb-upload.html, with screenshots and capability counts. [WebGL extension](https://github.com/KhronosGroup/WebGL/blob/39443210f7f81db4773eb104facadfb85d05dfa4/extensions/EXT_sRGB/extension.xml)
