# WebGL context method receivers and prototype enumeration

The original expando-loss.html obtains methods from Object.getPrototypeOf(gl), applies them to the context and retrieves resource wrappers with their JS properties after collection. The current direct native prototype raises Illegal invocation on a Refral receiver. constants-and-properties.html also enumerates browser prototype members that the facade does not expose.

Provide a facade prototype shared per canvas realm, inheriting the WebGLRenderingContext prototype for instanceof. Its WebGL operations must dispatch on the actual receiver via a private association. Preserve per-context resource wrapper identity, user expando properties, lost/restored dispatch, extracted-method brand validation and the native browser prototype. Expose the initial drawingBufferFormat and public RGB8 constant from the pinned WebGL1 default-buffer rules. Report unsupported optional APIs separately. Refral owns the facade, the spec mapping, the support record and the public identity fixture. This task requires no Wasm ABI change.

Run pnpm check, the headless public interface checks for both actual cores and Chrome, and the unchanged expando-loss, constants-and-properties, instanceof-test and Offscreen methods originals. Inspect the execution record for every backend, including any extra native vendor operation.

On the frozen integration build, expando-loss passed 51 assertions on each backend, including bindings and attachments after garbage collection. Constants and properties passed 4/0 on each. Refral JS and Rust each passed all nine selected originals. Native passed seven of nine. Its two Offscreen method files each reported 1/1 because Chrome 158 exposes the additional enumerable texElementSubImage2D method. No expected WebGL1 operation was missing on Chrome. The portable direct-factory checks exercise cross-context method dispatch, forged receiver rejection, both initial effective formats and resource identities on all three paths. The optional unpackColorSpace and XR surfaces remain outside this verified scope.
