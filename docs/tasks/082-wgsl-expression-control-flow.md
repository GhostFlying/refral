# WGSL expression statements, function fallthrough and component l-values

Task 082 depends on the task 078 compiler candidate, the fixed WebGL 1.0.4 suite and the existing exclusive headless Chrome runner. Work is limited to the pinned ANGLE translator adaptations, compiler acceptance fixtures, support/spec mapping and this record. Task 073 owns point I/O.

1. Compile and run the originals `conformance/glsl/bugs/logic-inside-block-without-braces.html`, `deqp/data/gles2/shaders/functions.html` and `conformance/glsl/bugs/assign-to-swizzled-twice-in-function.html`. Capture the first WGSL validation error and assertion counts in all three backends.
2. In separate commits, preserve ESSL expression-statement side effects and short circuiting, preserve non-void functions' taken return values and permit fallthrough, and lower expression-valued writes to vector components without constructing a WGSL pointer to the component. Use ANGLE's existing typed AST transforms where applicable.
3. For each commit build `pnpm compiler:build`, run `pnpm compiler:test`, compile independent WGSL modules and execute the corresponding complete original file in a detached checkout. A typed pixel fixture should exercise taken and skipped operands, function return values and intermediate component writes. Run the combined compiler browser suite and all three originals on the final revision using native, JS and actual Wasm. Record any remaining diagnostics or dependencies.

ESSL 1.00 §§5.5, 5.8–5.9, 5.13 and 6–6.4 cover assignments and l-values, conditional evaluation, expression statements and non-void function return semantics. The chosen fallback for a fallthrough value is observable only where ESSL leaves that value undefined. WGSL accepts a discard assignment for ordinary value expressions and requires a return or another exit on every path in a value-returning function. Its address-of operand cannot be a vector component. Preserve the original ESSL source, typed side effects and upstream assertions.

The 078 baseline completed all three originals. Native returned 3/0 for short-circuit logic, 2/0 for the swizzle and 13045/0 for the dEQP functions file. JS and Rust each returned 1/2, 1/1 and 12471/4. The dEQP's four messages are two incorrect-pixel reports and their two color warnings, one pair each for missing_returns_vertex and missing_returns_fragment. The first WebGPU errors were an expression in statement position, an address-of operation on a component, and a missing non-void return. Raw results and screenshots are in the baseline checkout's `artifacts/conformance/baseline-082/{native,js,rust}`.

The fallthrough change runs ANGLE’s existing AddDefaultReturnStatements on the typed AST for WGSL. The focused fixture returns a vec2 from a conditional branch and verifies both components. The original dEQP case exercises float returns in both shader stages with three positive inputs.

The short-circuit original reached 3/0 on each backend after the first commit. Its shared pixel fixture also exercises taken operands and counts exactly six side effects. After the second commit the full dEQP functions original returned 13045/0 on Chrome and 12545/0 on each compatibility core with zero recorded GPU validation errors. The third change extends ANGLE's typed assignment helper to take the enclosing vector address and a component index. It evaluates the RHS once, updates only the selected scalar and returns the original or updated value according to the operator. Its draw fixture covers a private vector, a local vector, index expressions using a loop variable, a nested chain, compound assignment and both forms of increment. Each fragment module also passes the standalone Naga WGSL validator.

The three changes together passed the swizzle original 2/0 and short-circuit original 3/0 on all three backends. The full dEQP functions original reported native 13045/0 and both compatibility cores 12545/0. Eight adjoining original files for sequence operators, swizzlers, short circuiting, shader globals and uniform location lengths also passed on every backend. The fixture produced [0, 255, 0, 255] for every shader and backend. For integration with task 073, the point-sprite patch and these expression patches touch separate ANGLE paths. Their combined Wasm was built and eight point/nonpoint vertex and fragment modules passed Naga. The regular `compiler:build` checks all patches against the pinned revision. Full focused results and screenshots use `artifacts/conformance/focused/{native,js,rust}` and the three-way pixel fixture writes `artifacts/compiler/expression-side-effects.json`.
