## Selection and independent observations

The selection starts from each of the 971 original URLs and follows its local HTML script/iframe, Worker, importScripts, script URL and dEQP Closure module references. Of the 1,057 sources traversed, 11 original pages name one of the extensions directly and 10 additional pages reach a source that names one through shared helpers. Including dynamic lookup, enumeration, prefixed extension helpers and 31 dEQP shader-library controls yields 90 unique URLs. The 90-file denominator describes this review. Some shared code is reachable but only executes under other optional capabilities. The selection stores each triggering upstream file, line and dependency path.

The stock quiet runner suppresses successful DOM log lines. A separate 14-file run therefore captured matching original assertion messages at the existing reporter callback. Native, JS and Rust each passed 14/14, with 1,554 native and 1,139 per-core passing assertions. In get-extension.html the two new names exercise mixed-case lookup, repeated identity, matching properties and prefixed-name handling, increasing each core's passing assertions from 15 to 29. In ext-float-blend.html the core reaches the optional WEBGL_color_buffer_float availability check after obtaining OES_texture_float. The sRGB upload original verified its GREY50 texture pixels for input arrays and video. These observations are in branch-witness.json and witness/{native,js,rust}/results.json.
