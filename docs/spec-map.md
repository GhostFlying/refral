## WebGL1 interface and vertex input

GLES 2.0.25 sections 2.1.2, 2.6 and 2.8 define primitive assembly, vertex array element layout and conversion. WebGL accepts BYTE, UNSIGNED_BYTE, SHORT, UNSIGNED_SHORT and FLOAT. Valid sizes are 1–4. Stride zero uses the element size. Offset and stride use byte units and must be multiples of the component size. Negative offsets or strides and stride above 255 produce INVALID_VALUE. Misalignment and a nonzero offset with no bound ARRAY_BUFFER produce INVALID_OPERATION. A rejected pointer update retains the earlier state. [Pinned vertex pointer](https://github.com/KhronosGroup/WebGL/blob/39443210f7f81db4773eb104facadfb85d05dfa4/specs/latest/1.0/index.html#L3412)

An enabled array with no buffer produces INVALID_OPERATION at draw, including an array unused by the active program. An enabled, bound array consumed by the program must cover the selected vertex indices. An unused bound array may be short. Integer input converts to float directly or through normalized conversion. The implementation uses WebGL1's permitted zero-preserving signed rule, max(c / (2^(bits-1) - 1), -1), and unsigned c / (2^bits - 1). Triangle strips alternate winding, and their indexed path treats 65535 as a valid WebGL1 index. WebGPU reserves the all-ones value of the strip index format for restart. [Pinned range checking](https://github.com/KhronosGroup/WebGL/blob/39443210f7f81db4773eb104facadfb85d05dfa4/specs/latest/1.0/index.html#ATTRIBS_AND_RANGE_CHECKING) · [Pinned signed conversion](https://github.com/KhronosGroup/WebGL/blob/39443210f7f81db4773eb104facadfb85d05dfa4/specs/latest/1.0/index.html#L4585) · [WebGPU index format](https://www.w3.org/TR/webgpu/#enumdef-gpuindexformat)

## Packed typed texture input
